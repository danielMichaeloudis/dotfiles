# Dotfiles

This git repo contains dotfiles for my saystem.

## Requirements

To use this repo ensure you have the following installed on your system.

- (Git)[https://git-scm.com/]
- (Stow)[https://www.gnu.org/software/stow/]

## Installation

To install this repo and use the dotfiles here:

1. Clone this repo into your home directory.

`git clone https://github.com/danielMichaeloudis/dotfiles ~/dotfiles`

2. Ensure that any dotfiles found in this repo do not exist in the same directory relative to your home directory.
3. cd into the dofiles directory.
4. Run the stow command.

`stow .`

For more information see the Youtube video by (Dreams of Autonomy)[https://www.youtube.com/watch?v=y6XCebnB9gs]
